# Origin 绘图参数

本文说明 GUI 中的绘图和数据处理参数。安装和启动步骤见[项目主页](../README.md#快速开始)。

在主窗口顶部点击“Origin 绘图参数…”。源码版也可以双击 `Origin-Settings.cmd` 单独打开。

## 怎么填

先在模型结果列表中确认要绘制的结果，再填写对应的 Tag 和 X/Y 列。绘图设置选中的结果必须与本次提取的结果一致。

参数窗口分为五页：

- **曲线与数据**：结果 Tag、数据列、图型，以及各条曲线的颜色、线型和图例文字。
- **坐标轴**：标题、单位、范围、刻度间隔及线性/对数坐标。
- **字体、图例与布局**：字体、字号、图例位置和图层边距。
- **尺寸与导出**：图片宽高、DPI、文件格式、透明背景和输出位置。
- **数据处理**：无效值清理、排序、平滑和插值。

X/Y 列填写去掉单位后的表头名称。单位文字只用于标注，不会换算数据。对数坐标要求所选数据大于零。

## 保存设置

点击保存后，程序会检查参数。参数不合法时会提示原因，不覆盖原配置；保存成功后，上一份配置保留为 `config.toml.ui-backup`。

下次提取会读取新设置，不需要重启程序。EXE 的配置位于 `%LOCALAPPDATA%\COMSOLOrigin\config.toml`，源码版位于项目目录。

## 在同一工程中生成多张图

在主程序的“COMSOL 读取与 Origin 绘图”窗口里识别数据、选择 X/Y，并设置图形类型、坐标轴等参数。点击“加入当前图”，再设置下一张图并继续加入。列表中选中一项后，可以用当前参数替换，或移除这一项。尚未加入的修改不会参与批量绘图。

点击“在同一 Origin 工程中生成全部…张图”，每项会生成独立的工作簿和图窗。“COMSOL 读取”页里的 Origin 显示及工程保存设置对整批图共用；勾选“保存 Origin 工程”即可把全部图存入一个 OPJU。批量导出的图片和处理后 CSV 按列表顺序加 `-01`、`-02` 等后缀。列表只保留在当前窗口，需要跨次使用的参数可用“参数记忆”单独保存。

## 开发检查

运行 `python scripts/verify_settings_ui.py` 可以检查页签、设置保存和主窗口按钮。截图输出到 `output/settings_preview/`。

这个脚本不启动 COMSOL 或 Origin，只检查界面和配置读写。实际提取、绘图与导出需要另做检查。

## 参数记忆

调整参数后，在窗口顶部输入名称，点击“记忆当前参数”，可保存多套参数，重启后仍可使用。同名记忆会先询问是否覆盖。记忆包括曲线、坐标轴、字体、布局、导出和数据处理设置。

选择已记忆的名称，点击“载入”，再点击“保存设置”应用到绘图。记忆和载入本身不会覆盖正在使用的配置，取消窗口可放弃未应用的调整。

选择名称后点击“删除记忆”，确认后删除该预设；当前参数和其他预设保持不变。预设保存在当前配置目录的 `parameter_presets.json`，已加入 Git 忽略规则。
